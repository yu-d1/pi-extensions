# @liziy/db-plugin

让 AI 直接查你的数据库（PostgreSQL / MySQL / Oracle）。配好连接后，AI 知道有哪些库、哪些表、表里有什么字段，你直接说需求就行，不用粘 SQL、不用切工具。

## 安装

```bash
pi install npm:@liziy/db-plugin
```

重启 pi 生效。

## 快速上手

1. `/db` → `编辑` → `新增连接`
2. 填：类型 → 主机 → 端口 → 账号 → 密码 → 名称（库名可留空）
3. 保存时自动测连通性
4. 保存后勾选要开放给 AI 的库
5. 直接跟 AI 说需求

```
「查一下 jetlinks 里最近 10 条设备记录」
「74 上 wm_waterquality_hour_records 有哪些字段」
「统计 gt_quartz 的定时任务表结构」
```

## 命令

`/db` 打开菜单：

```
启用    开关连接本身，以及连接下哪些库对 AI 开放
编辑    修改已有连接，底部可新增
查看    列出所有连接（含账号密码）
删除    删除连接，二次确认
设置    只读模式 / 最大行数 / 查询超时
```

也可直接输子命令：`/db enable`、`/db edit`、`/db view`、`/db rm`、`/db config`、`/db reset`。

## 连接与库

一个连接 = 一台服务器，下面可以挂多个库。同实例的 `jetlinks`、`gt_cloud`、`gt_quartz` 只需配一个连接，勾选要开放的库即可。

- 库名可留空，保存后自动扫描服务器上有哪些库
- 只启用一部分也行，未启用的库 AI 完全看不到
- Oracle 例外：必须填服务名，一个服务名一条连接

### 启用界面

`/db` → `启用` → 选连接：

```
启用 - pg_79
勾选的库对 AI 开放

> 搜索或输入新库名…

→ ✓ 连接本身  192.168.250.79:5432
  ✓ gt_monitor
  ✓ gt_quartz
  ✗ postgres
  ✗ wvp

  空格 切换 · ^a 全选 · ^x 清空 · ^s 保存 · esc 完成
```

| 按键 | 作用 |
|------|------|
| `↑` `↓` | 移动光标 |
| `空格` | 切换勾选 |
| 输入字符 | 实时搜索 |
| 输入新名 + `回车` | 新增库并勾选 |
| `^a` / `^x` | 全选 / 清空 |
| `^s` | 保存，留在界面继续调 |
| `esc` | 完成 |

「连接本身」置顶，停用后该连接下所有库都不对 AI 开放。始终至少保留一个启用的库。

### 编辑连接

每项显示当前值，`回车` 保持原值，输入新内容覆盖，输入 `-` 置空。改了地址、端口、账号或密码会自动重测连接。

## 设置

| 设置项 | 默认值 | 可选值 |
|--------|--------|--------|
| 只读模式 | 是 | 是 / 否 |
| 最大行数 | 500 | 1 / 50 / 500 / 不限制 / 自定义 |
| 查询超时 | 15s | 正整数秒 |

只读模式开启时 AI 只能查询，写操作会被拒绝。无论开关如何，`DROP TABLE`、`DROP DATABASE` 等删除结构语句始终禁止。

## 配置文件

| 文件 | 内容 |
|------|------|
| `~/.pi/agent/db-configs.json` | 连接列表（**密码明文**） |
| `~/.pi/agent/db-plugin-config.json` | 只读模式、最大行数、查询超时 |

设置 `PI_CODING_AGENT_DIR` 可改变目录。密码明文保存，注意文件权限，不要提交到版本库。
