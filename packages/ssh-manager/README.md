# @liziy/ssh-manager

pi 的 SSH 连接管理扩展。

通过 `/ssh` 命令添加、编辑、删除本地 SSH 连接配置。选择后可一键复制 ssh 命令或 `~/.ssh/config` 片段。

## 特性

- **统一命令** — `/ssh` 一个命令，参数控制子操作
- **OS 自动探测** — 自动扫描 `~/.ssh/` 下的 ed25519 / rsa / ecdsa / dsa 密钥
- **连接测试** — 添加时自动测试连接是否可达
- **多平台** — Windows / macOS / Linux 通用，密钥路径通过 `homedir()` 自动适配
- **本地存储** — 配置保存到 `~/.pi/agent/ssh-configs.json`

## 安装

```bash
pi install npm:@liziy/ssh-manager
```

## 使用

### /ssh 子命令

| 命令 | 作用 |
|------|------|
| `/ssh` | 列出并选择连接查看详情 |
| `/ssh add` | 新增连接 |
| `/ssh edit` | 编辑已有连接 |
| `/ssh rm` | 删除连接 |
| `/ssh ls` | 同 `/ssh`（默认） |

### 新增流程

```
1. IP 地址          [必填]
2. 用途说明          [可选]
3. 用户名           [默认: 当前系统用户]
4. 端口             [默认: 22]
5. 密码             [可选，留空使用密钥]
6. 密钥路径          [从 ~/.ssh/ 自动探测]
7. 连接名称          [默认: 从 host 派生]
```

### 编辑流程

- 顶部明确回显所有当前值
- 每个字段标题包含"当前: x"
- 留空 = 保持当前值
- 输 `-` = 清空说明字段
