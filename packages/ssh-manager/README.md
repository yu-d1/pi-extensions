# @liziy/ssh-manager

让 AI 帮你操作服务器。配好 SSH 连接并启用后，AI 可以直接在远程机器上执行命令、看日志、查进程。

## 安装

```bash
pi install npm:@liziy/ssh-manager
```

重启 pi 生效。

## 快速上手

1. `/ssh` → `编辑` → `新增连接`，填地址、端口、账号、密码或密钥
2. 保存时自动测试连通性
3. `/ssh` → `启用`，勾选要开放给 AI 的连接
4. 直接跟 AI 说「看看 web1 上的 nginx 日志」

## 命令

`/ssh` 打开菜单：启用 / 编辑 / 查看 / 删除 / 设置

也可直接进入：`/ssh enable`、`/ssh edit`、`/ssh add`、`/ssh view`、`/ssh del`、`/ssh config`、`/ssh reset`

## 启用界面

```
启用 - SSH 连接
勾选的连接对 AI 开放
空格切换，^a 全选，^s 保存，esc 完成

> 搜索连接名…

  ✓ web1      root@10.0.0.1:22
  ✓ db1       root@10.0.0.2:22
  ✗ test-box  root@10.0.0.3:22

  空格 切换 · ^a 全选 · ^x 清空 · ^s 保存 · esc 完成 · 已启用 2/3
```

停用的连接 AI 完全看不到，也不会出现在工具返回里。新增的连接默认启用。

## 编辑连接

每项显示当前值，`回车` 保持原值，输入 `-` 置空。认证方式可在密码和密钥之间切换，改了地址或认证会重新测连通性。

## 设置

| 设置项 | 默认值 | 可选值 |
|--------|--------|--------|
| 只读模式 | 是 | 是 / 否 |
| 执行确认 | 写操作确认 | 不确认 / 写操作确认 / 每次都确认 |
| 命令超时 | 30s | 5 / 15 / 30 / 60 / 120 / 自定义 |

**只读模式**开启时只能执行 `ls`、`cat`、`ps`、`df`、`tail`、`free` 这类纯查看命令，不允许管道、重定向、复合命令，也不允许 `sudo`、`git`、`docker`、`curl` 等可能产生副作用的命令。

**执行确认**命中时 AI 会被直接拒绝，需你手动操作，不会弹窗。

**无论怎么设置**，删除、格式化、关机重启、分区、改权限等破坏性命令始终禁止。

## AI 什么时候会连服务器

只有你明确提到服务器时 AI 才会连：说服务器名、IP，或上一轮已经在操作这台机器。

你没提的时候它不会自己跑上去看：

- 读代码、看本地配置、翻本地日志 → 用本地文件工具
- 查数据库的表结构与数据 → 用数据库插件，即使库就在已启用的服务器上
- 需要服务器上的运行时状况（进程、端口、磁盘、容器、服务状态）→ 才用 SSH

分不清你说的是本地还是服务器，它会先问一句。

## AI 工具

| 工具 | 用途 |
|------|------|
| `ssh_exec` | 在指定连接上执行命令 |
| `ssh_list_servers` | 查看连接详情与认证方式（连接名已在提示中，平时用不到） |

## 配置文件

| 文件 | 内容 |
|------|------|
| `~/.pi/agent/ssh-configs.json` | 连接列表（**密码明文保存**） |
| `~/.pi/agent/ssh-plugin-config.json` | 只读模式、执行确认、命令超时 |

设置 `PI_CODING_AGENT_DIR` 可改变上面的目录。

> 密码明文存储，注意文件权限，不要提交到版本库。能用密钥就用密钥。
