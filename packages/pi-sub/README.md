# @liziy/pi-sub

> 版本 1.0.0 — pi 子进程调度扩展：唤醒独立子进程执行任务（文件探索 / 审核 / 调研 / 看图）

pi 子进程调度插件：主进程通过 `sub` 工具唤醒独立的 `pi` 子进程执行任务，子进程拥有独立的模型、系统提示词与工具，结果以文本返回，不污染主会话。

## 特性

- 内置 `file-scout`（文件探索）、`review`（只读审查）、`research`（联网调研）、`vision`（图片理解）四个只读子进程
- 实时输出：直接透传子进程真实输出，固定显示最新 5 行（`/sub` → 通用设置可调 1-10 行）
- `tools: plan`：授予全部只读工具，以后新增的扩展工具自动可用
- 主模型可一键生成新的子进程配置

## 安装

```bash
pi install npm:@liziy/pi-sub
```

## 使用

| 命令 | 作用 |
|------|------|
| `/sub` | 打开菜单：配置子进程 / 新增子进程 / 通用设置 / 删除 |
| `/sub <agent> [任务]` | 直接运行指定子进程 |
| `/sub list` | 查看子进程清单 |

主模型也会按各子进程配置里的 `prompt` 触发规则自动调用 `sub`。

## 新增子进程

`/sub` → 新增子进程 → 描述需求，主模型生成完整配置并写入：

```text
~/.pi/agent/extensions/pi-sub/agents/<name>.md
```

写入后执行 `/reload`。用户目录中的同名文件覆盖内置配置，不会改动 npm 包文件。

## 配置要点

- `tools`：`plan` 表示全部只读工具（自动排除 edit/write 及交互类）；或写逗号分隔的工具白名单
- 实时输出固定显示行数：默认 5 行（`/sub` → 通用设置调整）

## 环境变量

```text
PI_SUB_PI_BINARY    # 指定子进程使用的 pi 可执行文件（可选）
```
