# @liziy/pi-sub

> 版本 1.0.3 — pi 子进程调度扩展：唤醒独立子进程执行任务（文件探索 / 审核 / 调研 / 看图）

pi 子进程调度插件：主进程通过 `sub` 工具唤醒独立的 `pi` 子进程执行任务，子进程拥有独立的模型、系统提示词与工具，结果以文本返回，不污染主会话。

## 特性

- 内置 `file-scout`（文件探索）、`review`（只读审查）、`research`（联网调研）、`vision`（图片理解）四个只读子进程
- 实时输出：直接透传子进程真实输出，固定显示最新 5 行（`/sub` → 通用设置可调 1-10 行）
- `tools: plan`：授予全部只读工具，以后新增的扩展工具自动可用
- 主模型可一键生成新的子进程配置
- 子进程支持启用/停用；未启用或未配置模型时，不会注入自动调用提示
- 子进程模型基于当前 `/model` 的筛选范围选择，不再默认绑定固定模型
- 图片任务会预先检查模型图片能力，不支持图片时立即返回；子进程默认最长运行 3600 秒，可在“通用设置”中调整

## 安装

```bash
pi install npm:@liziy/pi-sub
```

## 使用

| 命令 | 作用 |
|------|------|
| `/sub` | 打开菜单：配置子进程 / 新增子进程 / 通用设置 / 删除 |
| `/sub <agent> [任务]` | 直接运行指定子进程 |
| `/sub list` | 查看子进程清单 |
| `/sub` 配置子进程 | 可连续修改启用状态、模型和思考等级；完成当前子进程后可继续配置其他子进程 |

主模型也会按各子进程配置里的 `prompt` 触发规则自动调用 `sub`。

## 新增子进程

`/sub` → 新增子进程 → 描述需求，主模型生成完整配置并写入：

```text
~/.pi/agent/extensions/pi-sub/agents/<name>.md
```

写入后执行 `/reload`。用户目录中的同名文件覆盖内置配置，不会改动 npm 包文件。

## 配置要点

- `enabled`：是否启用，默认 `true`；设置为 `false` 后不会注入该子进程的自动调用提示
- `model`：后端模型，必须从当前 `/model` 筛选范围中选择；未配置时不会注入自动调用提示
- `thinking`：思考等级，可选 `off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`
- `tools`：`plan` 表示全部只读工具（自动排除 edit/write 及交互类）；或写逗号分隔的工具白名单
- 实时输出固定显示行数：默认 5 行（`/sub` → 通用设置调整）
- 子进程超时时间：默认 3600 秒，可在 `/sub` → `通用设置` → `子进程超时时间（秒）` 中修改，允许范围为 1-86400 秒

配置菜单中修改字段后会立即保存，并继续停留在当前子进程配置页面。选择「完成当前子进程」返回子进程列表，选择「完成配置」退出配置流程。按 `Esc` 会按当前菜单层级返回，不会丢失已经保存的修改。

## 图片与超时

通过 `sub` 工具传入 `images` 时，插件会先检查所选后端模型是否支持图片输入。若不支持，会在启动子进程前直接返回错误，不会让子进程进入无响应等待。

子进程默认最长运行 `3600` 秒（1 小时）。超过时间仍未返回时会自动终止，并返回超时错误。可以通过 `/sub` → `通用设置` → `子进程超时时间（秒）` 修改，修改后下次运行子进程生效。

## 环境变量

```text
PI_SUB_PI_BINARY    # 指定子进程使用的 pi 可执行文件（可选）
```
