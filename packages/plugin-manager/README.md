# @liziy/plugin-manager

pi 插件管理器 —— 按来源（MCP 服务器 / 扩展 / 技能）一键关闭不需要的能力，节省上下文 token。

## 命令

```
/plugins                   打开管理界面，勾选启用/禁用（TUI 下为批量勾选组件，ctrl+s 保存后留在界面）
```

底部状态栏显示 `🧩 已启用/总数`。

## 管理界面

TUI 模式下为批量勾选组件（与内置 `/scoped-models` 交互一致）：

```
────────────────────────────────────────────

插件管理
勾选 = 启用该来源的工具；未勾选的不注入上下文 · ctrl+s 保存

→ context7      [MCP] (3 工具, ~1.2K)  ✓
  github        [MCP] (12 工具, ~8.5K) ✓
  file-scout    [扩展] (6 工具, ~3.0K) ✓
  vim-mode      [扩展] ✗
  pdf           [技能] ✗

  enter 切换 · ctrl+a 全选 · ctrl+x 清空 · ctrl+s 保存 · esc 取消 · 已启用 3/5
────────────────────────────────────────────
```

- **↑↓** 选择、输入关键词模糊搜索过滤、**enter** 切换勾选
- **ctrl+a** 全选 / **ctrl+x** 清空（有搜索词时只作用于过滤结果）
- **enter** 切换勾选；**ctrl+s** 保存并留在当前界面继续调整（footer 显示已保存）；**esc** 退出
- **ctrl+a** 全选 / **ctrl+x** 清空（有搜索词时只作用于过滤结果）
- 勾选的条目始终排在最上面；条目多时不再需要分类二级菜单
- 非 TUI 模式（rpc/print）自动降级为循环单选切换

## 安装

```bash
pi install npm:@liziy/plugin-manager
```

重启 pi 或 `/reload` 生效。
