# @liziy/session-queue

pi 会话树文件检查点：每个 turn 自动记录文件快照，`/rollback` 选择对话即可恢复文件并跳转到该对话发送前。各分支维护独立文件状态。

## 安装

```bash
pi install npm:@liziy/session-queue
```

## 使用

```bash
/rollback    # 首次进入 → 启用当前工作区，之后每个 turn 自动记录检查点
```

主菜单：

```
📋 回滚历史（树形）  选择对话 → 回滚文件并跳转
📂 管理工作区        启用 / 停用 / 删除工作区
⚙️  全局配置         队列保留数、清理策略、跟随 Session Tree
🗑️  清空当前队列
♻️  回收孤儿快照
🚪 退出菜单
```

## 特性

- **自动检查点**：edit / write / bash（rm、mv、重定向）后按 sha256 快照落盘
- **树形历史**：与 `/tree` 一致的分支结构，切换分支只重放该分支变更，其他分支记录保留
- **对话定位**：复用 pi `/tree` 组件，回滚后同步跳转；「跟随 Session Tree」开启后 `/tree` 导航自动回滚
- **冲突保护**：文件被外部修改时提示冲突，可选强制覆盖或跳过

## 说明

- 只记录「已启用工作区」内的文件变更
- 保留最近 N 个队列（默认 10），孤儿快照手动回收
- Git Bash `/tmp` 会导致 rm/mv 跟踪失效，bash 建议使用 `C:/...` 路径
