# @liziy/session-queue

把 pi 会话里的每个 turn 变成「文件检查点」，回滚到任意时刻（**执行前 / 执行后**）一键还原文件。
检查点按会话树组织，**各分支维护独立文件状态**，互不干扰。

---

## 安装

```bash
pi install npm:@liziy/session-queue
```

---

## 快速上手

```bash
# 进入项目目录，首次启用记录
/rollback
# → 主菜单 → "✅ 启用当前工作区"

# 正常使用 pi：每个 turn 结束时自动写入一个检查点（快照存 sha256 内容）
# 状态栏出现 "● 记录"（青）或 "● 同步"（绿）

# 想撤回某一步？
/rollback
# → 主菜单 → "📋 回滚历史（树形）"
# → 在树形列表选一个检查点
# → 选择「回滚到执行前」或「回滚到执行后」→ 文件还原
```

---

## 核心能力

- **自动检查点**：每个 user turn 结束时，把该 turn 修改的文件（edit / write / bash 的 rm、mv、重定向）记录成检查点，内容以 sha256 快照落盘。
- **树形历史**：检查点按会话树组织（与 `/tree` 结构一致），`/rollback` 里用缩进分支线展示，当前节点带 `▶` 标记。
- **分支独立状态**：切换到某分支只重放该分支路径上的变更，其他分支记录全部保留，可随时切回（= 不同分支改不同文件）。
- **执行前 / 执行后双语义**：每个检查点对应两种文件状态，可在 `/rollback` 选择：
  - `回滚到执行前`：该操作开始前
  - `回滚到执行后`：该操作完成后
  - 与 `/tree` 一致：停在 user 消息 = 执行前；停在其后消息 = 执行后。
- **导航自动同步**：开启「跟随 Session Tree」时，`/tree` 切分支会自动把文件切到对应节点状态。
- **冲突保护**：文件被外部修改时（磁盘 ≠ 记录状态）检测为冲突，提示后你可选择强制覆盖或跳过。

## 交互速览（`/rollback`）

```
主菜单（标题显示当前分支）
  📋 回滚历史（树形）      → 树形选择检查点
  📂 管理工作区
  ⚙️ 全局配置
  🗑️ 清空当前队列
  🧹 回收孤儿快照
  ❌ 退出菜单

选择检查点后的一键操作面板：
  ▶ 回滚到执行前
  📌 回滚到执行后
  ❌ 取消
```

---

## 重要说明

- **工作区边界**：只记录「已启用工作区」内的文件变更（`/rollback` → 管理工作区 可增/停/删）。要回滚某项目的修改，请启用该项目所在目录为工作区。
- **bash 路径**：建议 bash 命令用 Windows 风格路径（`C:/...`）；Git Bash 的 `/tmp` 会被解析为盘根导致 rm/mv 跟踪失效。
- **快照 GC**：保留最近 N 个队列（默认 10），孤儿快照可手动回收。

- **0.3.0** 回滚计划/执行分离、冲突跳过、residual 重试；Git Bash `/tmp` 路径解析修复提示。

- **0.1.x** 初始版本：线性队列 + 文件快照 + 简单回滚。
